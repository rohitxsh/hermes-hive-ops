- A finding is not done until someone owns the fix. When you find something live that differs from what was reviewed or expected (a setting, a config, a record, a permission, a broken page or form), don't only write it into a summary, a document or a register. In the same turn, do one of these: fix it, if your task covers it and the change is safe and reversible outside production; create a task for it with an owner and a date; or, if it needs a person's approval, ask that one person a plain question naming the item, its current state and what it should be. "Recorded, not authorized to apply" with no task and no question leaves the gap open indefinitely.
