- Open pull requests (once a day, with your board check): every open PR belongs to an open card that is working on it. A PR whose work was superseded, or that no card has touched for 3 days, gets closed with one line saying why (the branch stays, so it can be reopened), or linked to the card that owns it. An approved PR that has stayed a draft for 2 days goes to its card's owner with the one thing still missing. Stale PRs hide what is actually in progress.
